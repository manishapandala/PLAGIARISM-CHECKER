Design (marks, channels, interactions): This dashboard combines compact KPI cards, donut ratios, grouped bar charts, trend columns, and ranked records. Channels encode risk index (hazard proxy color/category), discovery year (x/time), velocity/brightness (bar length and groups), and closest approach distance (ranked list). Interactions include hazard-only toggle (high risk), risk filter dropdown, name search, and time-range chips.

Custom visualization category: Combinatorial. It merges multiple chart forms into a unified museum-style dashboard narrative rather than a single standard chart.

Source modification note: Inspired by a dashboard visual style reference; implementation and D3 logic written from scratch for this assignment.
